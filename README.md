# dagbok
python program to save training session.

## Usage

Run the calendar app with:

```bash
python calender.py
```

Commands in the app:
- `n` = next day
- `p` = previous day
- `m` = next month
- `l` = previous month
- `y` = next year
- `t` = previous year
- `u` = open selected day and add/edit/delete sessions
- `q` = quit

When you choose `u`, use:
- `1` = add session
- `2` = edit session
- `3` = delete session
- `4` = back to calendar

Sessions are saved automatically to `sessions.json`.
